技術與架構說明

本站採用單頁式靜態架構：所有遊戲共存於一份 DOM，透過 role="tablist" 切換 role="tabpanel"，爬蟲可讀取完整文字內容。JavaScript 以 IIFE 封裝，分為共用工具層（RNG、籌碼、播報）與各遊戲模組；Plinko 使用 Canvas 2D 搭配 requestAnimationFrame，其餘遊戲以 DOM 操作完成。

博弈遊戲的有限狀態機典型流程為 IDLE → SPINNING → EVALUATING → IDLE；本示範在各模組內實作相同概念，避免重複下注。行動端需特別處理 iOS Safari 首次互動音訊解鎖、觸控延遲與 WebGL/Canvas 情境遺失；本站未使用音訊或 WebGL，因此降低相關風險。
